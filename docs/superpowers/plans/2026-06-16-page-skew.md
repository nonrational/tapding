# Page Skew Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each sheet sits at a small, fixed, seed-stable angle in the platen; printed sheets stay square.

**Architecture:** A pure `pageSkew(seed, page)` helper in `geometry.ts` (reusing the existing seeded PRNG) returns a bounded angle; the renderer applies it as a `rotate()` transform when it creates a sheet. No model/storage change — the angle is a pure function of the already-persisted seed.

**Tech Stack:** Vite, TypeScript (strict), Vitest, vanilla DOM, CSS.

// Each sheet sits at a small fixed angle, stable per (seed, page) like cell jitter.
export const SKEW_MAX_DEG = 1.5;

export function pageSkew(seed: number, page: number): number {
  const r = seededRandom(hash(seed, page));
  return (r() - 0.5) * 2 * SKEW_MAX_DEG;
}
```

```

In `addSheet`, capture the page index and set the transform before appending:

```typescript
  private addSheet(): void {
    const sheet = document.createElement("div");
    sheet.className = "sheet";
    sheet.style.width = `${SHEET_W}px`;
    sheet.style.height = `${SHEET_H}px`;
    const page = this.sheets.length;
    sheet.style.transformOrigin = "center";
    sheet.style.transform = `rotate(${pageSkew(this.doc.seed, page)}deg)`;
    this.root.appendChild(sheet);
    this.sheets.push(sheet);
  }
```
